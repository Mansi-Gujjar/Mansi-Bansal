## 🧪 Research Interests

### 🔹 **Keller–Box Method**
- Implementing the Keller–Box scheme for solving nonlinear boundary-value problems  
- Studying accuracy, convergence, and stability  
- Building Python implementations for classical benchmark problems  

### 🔹 **Boundary-Layer Flows**
- Solving similarity-transformed ODE systems for steady/unsteady laminar flows  
- Working with Falkner–Skan equations, mixed convection, and coupled nonlinear systems  
- Analyzing flow behavior using numerical shooting, finite-difference, and Keller–Box approaches  

### 🔹 **Reproducing Research Paper Results**
- Recreating figures, tables, and residual plots from published fluid-mechanics and heat-transfer papers  
- Comparing numerical accuracy across methods  
- Documenting reproducibility and deviations from original results  

### 🔹 **Scientific Computing Tools**
- NumPy, SciPy, Matplotlib  
- Numerical ODE/PDE solving  
- High-precision computation, error analysis, and stability checks
